# 项目简介

> 虚构示例。机构、人物和数据均为虚构。

## 项目

星河学院传媒中心设备借用系统（原型）

## 提出人与用途

- 提出人：传媒中心设备室的产品负责人 `[用户]`
- 原型用途：给学院领导演示，争取正式立项 `[用户]`

## 要解决的问题

`[用户]` 设备室目前用一张 Excel 台账和纸质申请单管理借用：

- 同一个设备编号要在申请单和台账里各登记一次，常常对不上
- 贵重设备要部门负责人签字，申请单在办公室之间传递，经常一拖好几天
- 逾期全靠管理员每周翻台账发现，逾期费收不收、收多少因人而异
- 领导想知道设备使用率，没有现成的数据

## 判断标准

`[用户]` 系统有用的标志：

- 借用人不用再跑办公室找人签字
- 逾期当天就能发现
- 领导能随时看到借用统计

## 核心流程

1. **借用申请与审批**：借用人提交申请 → 检查借用记录和库存 → 管理员审批，贵重或校外使用时部门负责人再审批
2. **借出与归还**：签署协议 → 核对资产标签 → 借出 → 逾期检查 → 归还和收取逾期费

## 角色

借用人（学生、教师）、办事员、设备管理员、部门负责人。办事员和设备管理员同属设备室员工。

## 业务模式

物品借还 + 审批流 `[推断]`（已在阶段 0 向用户确认）
