# 术语表

|---|---|---|---|---|---|
| Borrower | | 借用人 | 角色、实体 | 申请借用设备的学生或教师 | 借用人 |
| Clerk | | 办事员 | 角色 | 在设备室柜台办理借出和归还 | 前台、经办人 |
| Manager | Equipment Manager | 设备管理员 | 角色 | 审批借用申请、管理等待名单、取消借用 | 管理员 |
| DeptHead | Department Head | 部门负责人 | 角色 | 审批贵重设备和校外使用，查看借用统计 | 主任 |
| Staff | | 设备室员工 | 角色 | 办事员和设备管理员的统称，都能办理归还 | — |
| LoanSystem | Loan System | 借用系统 | 系统 | 本系统，用于活动图中的系统泳道 | — |
| Registry | Asset Registry | 资产登记系统 | 外部系统 | 学院已有的资产系统，用来核对资产标签 | 资产系统 |
| Person | | 人员 | 实体 | 系统中所有用户的共同信息 | — |
| StaffMember | | 员工账号 | 实体 | 设备室员工和部门负责人的账号 | — |
| Loan | | 借用单 | 实体 | 一次借用，可以包含多件设备 | 借用登记、申请单 |
| Equipment | | 设备 | 实体 | 一件可借出的设备，以资产标签区分 | 设备 |

| Agreement | | 借用协议 | 实体 | 借用人在领取前签署的协议 | 借用协议 |
| LateFee | | 逾期费 | 实体 | 逾期归还时收取的费用 | 罚款 |
| AuditEntry | | 操作记录 | 实体 | 一次操作的留痕 | — |
| Notification | | 通知 | 实体 | 系统发给某个用户的一条站内消息 | — |
| LoanStatus | | 借用单状态 | 枚举 | 借用单的状态，值与状态机一致 | 状态 |
| BorrowerType | | 借用人身份 | 枚举 | Student 学生 / Teacher 教师 | 身份 |
| StaffRole | | 员工角色 | 枚举 | Clerk / Manager / DeptHead | — |
| ApprovalDecision | | 审批结论 | 枚举 | Approve 同意 / Reject 不同意 | — |
| Requested | | 已申请 | 状态 | 已提交，等待审批 | 待审 |
| Waitlisted | | 等待设备 | 状态 | 设备不足，在等待名单中 | 先登记 |
| Approved | | 已批准 | 状态 | 所有需要的审批都已同意，等待领取 | 已批 |
| Rejected | | 已拒绝 | 状态 | 审批不同意 | 不借 |
| Withdrawn | | 已撤回 | 状态 | 借用人撤回，或管理员取消 | — |
| OnLoan | | 借出中 | 状态 | 设备已借出 | 已借出 |
| Overdue | | 已逾期 | 状态 | 过了应还日期仍未归还 | — |
| Returned | | 已归还 | 状态 | 设备已归还，借用结束 | 已还 |
