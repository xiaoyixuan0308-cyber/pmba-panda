# 业务规则

| 编号 | 规则 | 出处 |
|---|---|---|
| BR-01 | 提交申请必须填写：借用人身份、设备（至少 1 件）、用途、使用地点（校内/校外）、借用日期、预计归还日期 | [材料: M2] (F13) |
| BR-02 | 审批人按决策表 DT-01 确定；只有所有需要的审批人都同意，借用单才算批准 | [材料: M3] (F10) [案例: GC-02] |
| BR-03 | 申请的设备在借用期间不足时，借用单进入等待名单；有设备归还后，系统通知设备管理员重新审核等待中的借用单 | [材料: M1] (F08) [用户] |
| BR-04 | 拒绝申请必须填写原因，并通知借用人 | [用户] |
| BR-05 | 借用人签署借用协议后，才能办理借出 | [材料: M2、M3] (F11) |
| BR-06 | 预计归还日期与借用日期的间隔不能超过 DT-02 规定的最长期限 | [材料: M3] (X1) [用户] |
| BR-07 | 过了应还日期仍未归还的借用单，在每日到期检查时标为已逾期，并通知借用人和设备管理员 | [案例: GC-01] [用户] |
| BR-08 | 批准前，借用人可以撤回申请；批准后到借出前，只能由设备管理员取消 | [材料: M3] (F14) [用户] |
| BR-09 | 借用单提交后 2 个工作日仍未审批完，系统提醒尚未审批的审批人 | [用户] |
| BR-10 | 逾期归还按每逾期 1 天 10 元收取逾期费，上限 200 元；不设免收 | [材料: M3] (F06) [用户] (X2) [案例: GC-03] |
| BR-11 | 办理借出时，必须在资产登记系统中核对每件设备的资产标签；任何一件核对不通过，整张借用单不能借出 | [材料: M2、M3] (F11) |
| BR-12 | 借用人名下有已逾期、尚未归还的借用单时，新的申请不能批准；以前有过逾期但已归还的，不作为拒绝理由 | [材料: M3] (F09) (X3) [案例: GC-03、GC-05] |
| BR-13 | 部门负责人可以按月查看借用统计：借用单数（按状态）、借出次数最多的 10 件设备、逾期率 | [用户] (E30) |

说明：

- "工作日"按周一至周五计算，不考虑节假日（用户确认原型阶段可以这样简化）。
- BR-07 中逾期从应还日期的次日开始计算，应还日期当天归还不算逾期。
- 以下 5 条是阶段 5b 中用户确认的澄清 [用户]（见 `reviews/5b-summary.md`）：
  - 借出期间，应还日期前 1 天提醒借用人一次（状态机 OnLoan 的 remindBeforeDue）。
  - 借用日期不能早于今天（BR-01 的填写校验）。
  - 过了应还日期、但每日到期检查还没运行就办理归还的，同样按 BR-10 收取逾期费。
  - 等待名单先到先得：设备空出时，只让最早提交、且所需设备都已空出的那张借用单回到"已申请"（BR-03）。
  - BR-09 的提醒只发给当前轮到的审批人：需要两级审批时，设备管理员同意后才提醒部门负责人。
- 借用单归还、离开"已逾期"状态时，该单的逾期提醒标为已处理（状态机 Overdue 的 exit 动作 closeOverdueAlert）。[用户]（2026-10-26 确认）
