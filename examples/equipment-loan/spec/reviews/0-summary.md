# 设备借用系统：启动评审

> 虚构示例

## 这一阶段确定了什么
- 系统要解决四个问题：重复登记、找部门负责人签字耽误时间、逾期发现太晚、领导看不到使用情况。
- 覆盖两个核心流程：借用申请与审批、借出与归还。
- 涉及四类人：借用人（学生和教师）、办事员、设备管理员、部门负责人。
- 借出时需要核对学院资产登记系统；原型中用模拟数据代替，不连接真实系统。
- 原型用于向学院领导演示，争取正式立项。

## 必须遵守的约束
- 借用人的手机号只有设备室员工能看到完整号码。
- 借用记录保留 3 年，不能删除。
- 每次审批、借出、归还和收费都要留下记录。
