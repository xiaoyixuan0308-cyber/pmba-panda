# 设备借用系统：原型第三步（界面）评审

> 虚构示例

## 这一步完成了什么
每个角色登录后直接进入自己的首页，导航里只出现自己能做的事：

| 角色 | 首页 | 主要页面 |
|---|---|---|
| 借用人 | 我的借用单：已逾期的醒目提示、明天到期的提醒、进行中和已结束的借用单 | 提交申请（手机上可用）、借用单详情（撤回、签署协议） |
| 办事员 | 柜台：今天待领取（标出是否已签协议）、今天到期和已逾期待归还、按编号/姓名/资产标签查找 | 办理借出（逐件核对资产标签，标注"模拟数据"）、办理归还（显示应收逾期费，必须勾选"已当场收取"） |
| 设备管理员 | 审核：运行到期检查按钮、待我审核、等待名单（按提交时间）、已逾期 | 审核页（"逾期未还"和"设备是否足够"两项检查并列显示，批准、拒绝、转入等待名单）、取消、操作历史、设置 |
| 部门负责人 | 待我审批（只有设备管理员已同意的）、本月概况 | 借用统计（按状态的借用单数、借出最多的 10 件设备、逾期率及计算方法） |

截图在 `reviews/5c/` 文件夹中，共 15 张。

## 怎么证明它是对的
| 检查 | 结果 |
|---|---|
| 角色走查：用浏览器以四个角色依次操作，从提交申请、审批、签协议、借出，到逾期归还收费 | 全部走通，每一步都检查了页面上的确认或错误信息 |
| 空表单提交 | 5 个必填项都在各自栏位下说明缺什么 |
| 借期超过上限 | 提示"这次最多可以借 14 天（DT-02 R1），你填写的是 22 天" |
| 已逾期的借用单办理归还 | 显示逾期 26 天、应收 200 元（已达上限），不勾选"已收取"不能归还 |
| 部门负责人查看借用单 | 手机号显示为 100****0012；打不开设置页 |
| 借用人打开别人的借用单 | 显示"找不到"（404） |
| 无障碍扫描（申请表单、审核页、柜台页） | 没有发现问题（WCAG 2 A/AA） |
| 正式构建、类型检查、代码规范检查 | 全部通过 |
| 第二步的 150 项自动测试 | 仍然全部通过 |

## 走查中发现并修正的问题
- 提交申请时如果有一项填错，改正后再提交，之前填好的"用途"和"使用地点"会被清空。已修正。
- 没有勾选同意协议就点"签署"，页面没有提示。已修正。
- 批准后审批区域消失，管理员看不到"已批准"的确认。现在会显示"你已于 某时 同意这张借用单，当前状态……"。
